# Development workflow

- Work in verifiable milestones. After each completed milestone, commit the
  relevant changes and push them to the configured remote.
- Run checks appropriate to that milestone before committing. Record unavailable
  checks and external blockers rather than claiming they passed.
- Include only the milestone's files; do not include unrelated work, game assets,
  extracted binaries, credentials, saves, or generated caches.
- Report the commit ID, push result, validation, and remaining limitations.
- Do not force-push. Inspect and reconcile remote changes when a normal push is
  rejected.

This workflow records the project owner's instruction of 2026-10-06.
